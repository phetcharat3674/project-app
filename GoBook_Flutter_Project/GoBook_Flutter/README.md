# GoBook — Flutter Demo

แอปต้นแบบจองตั๋วเดินทางและจองที่จอดรถสำหรับผู้ที่มีตั๋วเดินทางแล้ว

## ฟังก์ชันที่มี
- 4 แท็บนำทาง: หน้าหลัก, จองตั๋ว, ที่จอดรถ, รายการจอง
- หน้ายืนยันการจอง (หน้าจอที่ 5)
- เลือกต้นทาง/ปลายทาง, ประเภทรถ, วันเดินทาง, จำนวนผู้โดยสาร
- คำนวณค่าโดยสาร (รถทัวร์ 350 บาท/คน, รถไฟ 550 บาท/คน — ราคาตัวอย่าง)
- จองที่จอดรถหลังจากมีตั๋วเดินทาง, เลือกช่อง A1-A8
- คำนวณค่าจอด (30 บาท/ชั่วโมง — ราคาตัวอย่าง)
- ป้องกันการจองช่องเดียวกันในวันเดียวกันในข้อมูลของแอปนี้
- ยกเลิกตั๋วและที่จอดรถ
- บันทึกข้อมูลบนเครื่องด้วย shared_preferences; ข้อมูลยังอยู่หลังปิด/เปิดแอปใหม่

## วิธีเปิดโปรเจกต์บน Windows
1. ติดตั้ง Flutter SDK และ Android Studio (รวม Android SDK)
2. แตก ZIP นี้
3. เปิดโฟลเดอร์ `GoBook_Flutter` ด้วย VS Code
4. เปิด Terminal ในโฟลเดอร์โปรเจกต์ แล้วรัน:

```bash
flutter create --platforms=android .
flutter pub get
flutter run
```

หากคำสั่ง `flutter create` ถามว่าจะเขียนทับไฟล์ ให้เลือกไม่เขียนทับไฟล์ `lib/main.dart` และ `pubspec.yaml` (ถ้าใช้ Flutter รุ่นใหม่ คำสั่งมักสร้างโฟลเดอร์ android ให้โดยคงไฟล์แอปไว้)

ตรวจสอบสภาพแวดล้อมก่อนด้วย `flutter doctor` และเปิด Android Emulator หรือเชื่อมต่อมือถือที่เปิด USB debugging ไว้

## สร้าง APK
```bash
flutter build apk --release
```
ไฟล์ APK จะอยู่ที่:
`build/app/outputs/flutter-apk/app-release.apk`

## ข้อจำกัดสำคัญ
- เป็นโปรเจกต์ตัวอย่างเพื่อการเรียน ไม่ใช่ระบบขายตั๋วจริง
- ไม่มีการเชื่อมต่อผู้ให้บริการเดินทาง, ไม่มีชำระเงินจริง, ไม่มีบัญชีผู้ใช้/เซิร์ฟเวอร์
- การตรวจช่องจอดทำในข้อมูลที่บันทึกบนเครื่องนี้เท่านั้น ผู้ใช้คนอื่นจะไม่เห็นข้อมูลจองร่วมกัน
- ราคาและสถานที่เป็นข้อมูลจำลอง ปรับเปลี่ยนได้ใน `lib/main.dart`
